# Navigation Drawer

Android Navigation Drawer application using Material Design.

## Features

- **Navigation Drawer Menu**: Easy access to different sections of the app.
- **Screen Navigation**: Seamless transitions between application states.
- **Material 3 Interface**: Modern design following the latest Google standards.
- **Drawer Interaction**: Intuitive slide-out navigation panel.

## Tech Stack

- **Kotlin**: The primary language for Android development.
- **Jetpack Compose**: Modern toolkit for building native UI.
- **Material 3**: The latest evolution of Material Design.

## Project Structure

- `com.iren.navdrawer.MainActivity`: The entry point of the application.
- `com.iren.navdrawer.ui.navigation`: Contains navigation logic and routes.
- `com.iren.navdrawer.ui.screens`: Contains the individual screens of the app.
- `com.iren.navdrawer.ui.components`: Reusable UI components like the Navigation Drawer.
- `com.iren.navdrawer.ui.theme`: Design system implementation (Colors, Theme).

## Installation

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle and build the project.
4. Run the application on an emulator or physical device.
